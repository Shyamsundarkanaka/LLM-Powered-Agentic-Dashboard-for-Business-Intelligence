# LLM-Powered-Agentic-Dashboard-for-Business-Intelligence-for-Business-Intelligence

An LLM-powered Business Intelligence dashboard that leverages Large Language Models (LLMs) and agentic workflows to transform natural language queries into actionable insights, interactive visualizations, and data-driven recommendations.

## Features

- Natural language business data analysis
- Automated insight generation
- Interactive dashboards and visualizations
- Agentic workflow for intelligent query processing
- Dynamic chart and report generation
- Streamlit-based user interface

## Tech Stack

- Python
- Streamlit
- OpenAI API
- Pandas
- Plotly
- LangChain

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/LLM-Powered-Agentic-Dashboard-for-Business-Intelligence.git
cd LLM-Powered-Agentic-Dashboard-for-Business-Intelligence
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Create a `.env` file or set the environment variable:

```env
OPENAI_API_KEY=your_openai_api_key
```

## Run the Application

```bash
streamlit run stream_lit.py
```

## Usage

1. Launch the dashboard.
2. Upload a dataset.
3. Ask business questions in natural language.
4. Explore generated insights, charts, and recommendations.

## Example Queries

- What were the top-performing products last quarter?
- Show monthly sales trends by region.
- Which customers generated the highest revenue?
- Identify key business growth opportunities.
